# Guide videos

Narrated how-to videos built from a lesson script, a voice-over, and Whisper timings.

## Layout

```
guides/
  lessons/   <id>.json         lesson script (steps: headline, body, narration, tapWord?, screenshot, tap?)
  audio/     <id>.mp3          narration audio
  timing/    <id>.timing.json  generated by the align step (frames at 30 fps)
```

## Pipeline (run from `promo/`, in order)

1. Transcribe the narration with Whisper (word-level timings; writes `<out>.words.json`):

   ```
   powershell -File D:\Downloads\Tools\scripts\transcribe-words.ps1 -Audio guides\audio\<id>.mp3 -OutBase guides\audio\<id>
   ```

2. Align the script to the Whisper words (writes `guides/timing/<id>.timing.json`):

   ```
   node scripts/align.mjs guides/lessons/<id>.json guides/audio/<id>.words.json
   ```

   Fails with the step index and headline if a step's opening words are not found in the audio.
   Tests: `node --test scripts/align.test.mjs`.

3. Render the video (compositions `GuideLesson` 1920x1080 and `GuideLesson720` 1280x720, 30 fps):

   ```
   npx remotion render GuideLesson out/<id>.mp4 --props='{"lessonId":"<id>"}'
   npx remotion still GuideLesson out/still.png --frame=300 --props='{"lessonId":"<id>"}'
   ```

   The default `lessonId` is `sample-post-a-job`. Code: `src/guide/GuideLesson.tsx`, `src/guide/parts.tsx`.

## GuideLesson template

Length = title card (90 frames, 3 s) + `timing.durationFrames` + end card (120 frames, 4 s). Narration audio and
all timing frames are offset by the 90-frame title card. Lesson and timing JSON are read from `guides/lessons/<id>.json`
and `guides/timing/<id>.timing.json` (bundled by webpack, so no copy into `public/` is needed; they are looked up by `lessonId`).

Optional top-level lesson fields (besides `id`, `title`, `steps`):

| field | use |
|---|---|
| `track` | `"clients"` or `"providers"`: title-card tag reads "FOR CLIENTS" / "FOR PROVIDERS" |
| `number` | lesson number, shown in the tag ("FOR CLIENTS · 3") |
| `summary` | one-line summary on the title card |
| `next` | title of the next lesson, shown on the end card as "Next: ..." (omit for the last lesson) |

Step fields:

- `screenshot`: path **inside `promo/public/`** (e.g. `guide/post-a-job/01.png`), shown inside the phone frame (Android-style frame, 9:20 screen,
  filled with cover, aligned to the top; use a phone-shaped capture, an emulator capture such as 1080x2400). Use `placeholder:<label>` for a generated
  grey placeholder screen showing the label.
- `tap`: `{ "x", "y" }` as **fractions 0-1 of the screenshot** (x from the left, y from the top). The tap circle appears
  around the step's `tapFrame` (from the timing file; if a step has none, 24 frames after the step starts). No `tap`, no circle.

Audio: put the narration at `promo/public/guides/audio/<id>.mp3` (note: `public/`, separate from the `guides/audio/` Whisper
inputs above; copy the file there). If it is missing the video renders silent (the browser console logs one harmless 404 for it).
